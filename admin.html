अपनी अगली रचना प्रकाशित करने की तैयारी करें

अपनी वेबसाइट की फाइल चुनें, शायरी लिखें और नई index.html डाउनलोड करें।

1वेबसाइट फाइल चुनें
2रचना लिखें
3नई फाइल डाउनलोड करें

✦ रचना संपादक

अपनी मौलिक शायरी को सही रूप में वेबसाइट पर जोड़ें।

अभी कोई फाइल नहीं चुनी गई है।
—मौजूदा रचनाएँ
—फाइल की स्थिति
तुम्हारे शब्द जैसे लिखे हैं, वैसे ही जोड़े जाएँगे।
✓ नई वेबसाइट फाइल तैयार है

अब डाउनलोड की गई index.html को GitHub repository की पुरानी index.html से बदलकर Commit करें। पैनल स्वयं ऑनलाइन Publish नहीं करता।

LIVE WRITING PREVIEW

तुम्हारी रचना कैसी दिखेगी

यह सिर्फ रचना का पूर्वावलोकन है, लाइव वेबसाइट नहीं।

नई रचना — मोहब्बत

रचना का शीर्षक

यहाँ तुम्हारी शायरी दिखाई देगी…
✍ Ajab Singh
